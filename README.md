# Учебный проект CI/CD

## Описание
Это учебный проект, демонстрирующий настройку и работу непрерывной интеграции и доставки (CI/CD).  
Примеры включают автоматическую сборку, тестирование и развертывание кода.

## Для чего?
- Обучение принципам CI/CD.
- Автоматизация тестирования и деплоя.
- Практика с инструментами, такими как GitHub Actions, GitLab CI/CD или Jenkins.

## Технологии
- GitHub Actions / GitLab CI / Jenkins.
- Docker (опционально).
- Тестовые фреймворки (например, pytest для Python).
